## The Big Idea

Statistics becomes powerful when it answers business questions: *"Is this difference real, or just noise?"* This module teaches the core toolkit for group comparisons — the same methods used in A/B tests, clinical trials, and operational reviews.

Three key areas:

1. **Comparing Two Groups** (Day 61–63) — t-tests for independent and paired designs
2. **Comparing Multiple Groups** (Day 64–67) — ANOVA, post-hoc tests, and categorical comparisons
3. **Making It Meaningful** (Day 68–70) — effect size, power, and a full business case study

> A p-value tells you if a difference exists. This module teaches you if that difference matters.
