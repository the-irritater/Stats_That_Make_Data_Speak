## The Big Idea

Machine learning is not a separate discipline from statistics — it's what happens when statistical principles meet large-scale prediction. Every ML concept in this module has roots in something you already learned:

- **Train/test split** ← Sample vs Population (Day 3)
- **Overfitting** ← Variance and residual diagnostics (Day 7, 59)
- **Regularization** ← Ridge and Lasso (Day 77)
- **Feature importance** ← Coefficient significance (Day 72)

This module teaches you to think in ML terms while keeping your statistical rigor.

> The best ML practitioners are the ones who understand the statistics underneath.
